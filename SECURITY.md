# Security

If you find a security problem, do not open a public issue. Here, that means any of these:

- anything that gets a command past BALDUR-0;
- a forged or replayed act or request that the gate accepts;
- a way for ODIN to write its own event log;
- a key or secret in the repository.

Report it through GitHub's private vulnerability report on this repository, or write to dan.lee.odinson@gmail.com with the steps to reproduce. You will get a reply within a week.
