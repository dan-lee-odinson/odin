# BALDUR-0's command classes

Generated by `tools/class_table.py` from BALDUR-0's class configuration (`gateway/rules.py`); do not
edit it, regenerate it. It covers every command of HUGINN's dictionary v0.5, in the dictionary's order.

| Command | Class | Needs a lease |
|---|---|---|
| `CMD_PLD_SET_STATE` | C1 ROUTINE | Only while an envelope limit of the plan in force does not hold: then it counts as C4 |
| `CMD_PLD_SET_RATE` | C2 RECONFIGURE | Only while an envelope limit of the plan in force does not hold: then it counts as C4 |
| `CMD_SAFE_ENTER` | C3 PROTECT | Never. No plan can prohibit or restrict it, envelope limits never make it C4, and missing telemetry never blocks it |
| `CMD_SYS_RESET` | C3 PROTECT | Never. No plan can prohibit or restrict it, envelope limits never make it C4, and missing telemetry never blocks it |
| `CMD_MODE_SET` | C4 LEASED | Always: it is refused unless a lease in the plan in force covers it and the lease's conditions hold |

No plan can prohibit or restrict the C3 PROTECT commands, `CMD_SAFE_ENTER` and `CMD_SYS_RESET`: a plan whose prohibited list or leases name one fails verification (CONTRACT.md §5.5).

What each rung allows:

- HUMAN_ONLY: no command
- AI_AUTONOMOUS: C1, C2, C3, C4
