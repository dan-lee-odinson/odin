## The commands ODIN may send

| Command | Arguments | Class | COSMOS hazardous |
|---|---|---|---|
| `INST COLLECT` | `type` NORMAL only; `duration` 0.0 to 10.0; `opcode` 0 to 255 (0x00 to 0xFF); `temp` 0.0 to 25.0 | C1 ROUTINE | no |
| `INST ABORT` | none | C3 PROTECT | no |

Any other command, or any argument value outside these, is not in this dictionary. It is refused, by ODIN's answer check or by BALDUR-0, and counts as an attempted violation.
